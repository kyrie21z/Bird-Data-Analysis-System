# 首页模块顺序调整设计

## 目标

交换首页“区域观测分布”和“时空热力图”的位置，使时空热力图先出现、区域观测分布后出现。交换对所有屏幕尺寸生效，两个模块的内容、样式和功能保持不变。

## 实现方式

在 `frontend/index.html` 中交换两个完整 DOM 区块的顺序。调整后的相关页面结构为：

1. 物种分布与观测趋势
2. 时空热力图
3. 区域观测分布

每个模块携带其现有行容器和间距类一起移动。热力图的时间筛选按钮、地图、图例和 `heatmap-map` ID 保持原样；区域分布的卡片、柱状图和 `area-chart` ID 保持原样。

## 脚本与数据

无需修改 JavaScript、API 请求或事件处理。Leaflet 和 ECharts 均通过唯一元素 ID 查找容器，DOM 中的相对位置不影响初始化和数据绑定。物理交换 DOM 可确保视觉顺序、键盘顺序和辅助技术阅读顺序一致。

## 变更范围

仅修改 `frontend/index.html` 中两个模块的文档顺序。不修改后端、共享样式、图表配置、响应式断点、模块尺寸或其他首页区域。

## 验收

- `heatmap-map` 在文档中位于 `area-chart` 之前。
- `heatmap-map` 和 `area-chart` 各出现一次。
- 两个模块的内部标记在移动前后保持一致。
- 首页可由 Flask 正常返回，后端 Python 编译检查通过。
